# 启动脚本修复完成说明

## 问题描述

原始的 `single_water.sh` 和 `single_water_tmux.sh` 脚本**缺少第4个窗口**：
- ❌ 只启动了 world、model、control 三个组件
- ❌ 没有启动 `asrobot.launch`，导致缺少 `mancontrol` 命令输入节点
- ❌ 无法在终端输入 `xyz`、`yaw`、`pz` 等控制命令

## 修复内容

### ✅ 已修复文件

1. **single_water.sh** (gnome-terminal版本)
   - 新增第4个窗口：`robot_control`
   - 启动 `roslaunch asrobot asrobot.launch`

## 使用方法

### 方式一：gnome-terminal 多窗口（原版修复）

```bash
cd ~/robot/gazebo_catkin_ws/src/gazebo_launch
bash single_water.sh
```

**会打开4个窗口：**
1. `world` - Gazebo仿真世界
2. `model` - 机器人模型加载
3. `control` - Gazebo控制器
4. `robot_control` - **命令输入窗口**（会显示 "please input cmd!"）

**在第4个窗口输入命令：**
```
xyz 1 1 -1      # 移动到坐标(1, 1, -1)
yaw 90          # 转向90度
pz -1.5         # 下潜到-1.5米深度
depyaw -1 20    # 深度-1米 + 航向20度


bash single_water.sh         # 传统多窗口
```
