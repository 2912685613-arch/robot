# 脚本启动问题修复说明

## 问题描述

原始脚本使用 `gnome-terminal`，但在WSL环境下不可用。

## 解决方案

### 方案一：使用xterm（已完成）

所有原始脚本已修改为使用 `xterm` 替代 `gnome-terminal`：

```bash
# 修改前
gnome-terminal -t "world" -x bash -c "..."

# 修改后
xterm -T "world" -e bash -c "..."
```

**使用方法：**
```bash
cd ~/robot/gazebo_catkin_ws/src/gazebo_launch
bash single_water.sh        # 会打开多个xterm窗口
```

---

### 方案二：单终端tmux版本（推荐WSL用户）

创建了新的脚本 `single_water_tmux.sh`，使用tmux在单个终端中管理多个窗口。

**优点：**
- 不需要图形界面的多个窗口
- 更适合WSL和SSH环境
- 可以方便地切换查看不同组件的输出
- 更节省资源

**使用方法：**

1. **安装tmux（如果还没有）：**
```bash
sudo apt install tmux
```

2. **运行脚本：**
```bash
cd ~/robot/gazebo_catkin_ws/src/gazebo_launch
bash single_water_tmux.sh
```

3. **tmux基本操作：**
```
进入会话后的快捷键：
- Ctrl+b 然后按 0     # 切换到窗口0（Gazebo世界）
- Ctrl+b 然后按 1     # 切换到窗口1（机器人模型）
- Ctrl+b 然后按 2     # 切换到窗口2（控制器）
- Ctrl+b 然后按 d     # 暂时退出会话（仿真继续运行）
- Ctrl+b 然后按 [     # 进入滚动模式（可以查看历史输出）
  - q 退出滚动模式
```

4. **重新进入会话：**
```bash
tmux attach -t gazebo_sim
```

5. **完全关闭仿真：**
```bash
tmux kill-session -t gazebo_sim
```

---

### 方案三：直接在终端启动（最简单，但无法同时看所有输出）

如果不想安装tmux，脚本会自动退化为后台顺序启动模式。

## 完整的启动选项对比

| 方案 | 命令 | 优点 | 缺点 | 适用场景 |
|-----|------|------|------|---------|
| **xterm多窗口** | `bash single_water.sh` | 传统方式，每个组件独立窗口 | 需要X11显示，占用多个窗口 | 本地Linux桌面 |
| **tmux单终端** | `bash single_water_tmux.sh` | WSL友好，方便切换查看 | 需要学习tmux操作 | WSL、SSH远程 |
| **后台模式** | 运行tmux脚本但未安装tmux | 无需额外软件 | 无法方便查看各组件输出 | 快速测试 |

```bash
# 重新进入
tmux attach -t gazebo_sim

# 完全停止
tmux kill-session -t gazebo_sim
```

## 如果想恢复gnome-terminal

```bash
sudo apt update
sudo apt install gnome-terminal

# 然后恢复所有脚本（在gazebo_launch目录下）
for file in *.sh; do
  sed -i 's|xterm -T "\([^"]*\)" -e bash -c|gnome-terminal -t "\1" -x bash -c|g' "$file"
  sed -i 's|xterm -e bash -c|gnome-terminal -x bash -c|g' "$file"
done
```

## 故障排除

### xterm无法启动

如果xterm也无法使用，检查：

```bash
# 检查是否安装xterm
which xterm

# 如果没有，安装xterm
sudo apt install xterm

# 检查DISPLAY环境变量（WSL需要）
echo $DISPLAY

# 如果为空，设置DISPLAY（需要安装XLaunch或VcXsrv）
export DISPLAY=:0
```

### tmux会话连接问题

```bash
# 查看所有tmux会话
tmux ls

# 如果会话卡住，强制关闭
tmux kill-session -t gazebo_sim

# 清除所有tmux会话
tmux kill-server
```

## 推荐配置（可选）

为了更好的体验，可以添加到 `~/.bashrc`：

```bash
# 添加工作空间自动source
echo "source ~/robot/gazebo_catkin_ws/devel/setup.bash" >> ~/.bashrc

# 添加方便的别名
echo "alias sim_start='cd ~/robot/gazebo_catkin_ws/src/gazebo_launch && bash single_water_tmux.sh'" >> ~/.bashrc
echo "alias sim_stop='tmux kill-session -t gazebo_sim'" >> ~/.bashrc
echo "alias sim_attach='tmux attach -t gazebo_sim'" >> ~/.bashrc

# 重新加载配置
source ~/.bashrc
```

之后可以直接使用：
```bash
sim_start   # 启动仿真
sim_attach  # 重新连接
sim_stop    # 停止仿真
```
