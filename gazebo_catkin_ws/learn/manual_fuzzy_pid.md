# 手动控制的模糊 PID 总开关

启动 `bash src/gazebo_launch/single_water.sh` 后，在 command 窗口输入：

```text
fuzzypid on
```

默认开启。`fuzzypid off` 将手动 PID 切回固定增益；只有开关状态变化时才清空控制器历史。
旧的 `fuzzyxyz` 命令不再切换控制器，会提示使用新命令。

| 命令 | PID 通道 |
|---|---|
| `xyz 1 1 -1` | X/Y/Z 位置单环 |
| `dep -1` | Z 位置单环 |
| `yaw 30` | 航向单环，单位度，误差取 ±180 度内的最短方向 |
| `depyaw -1 30` | Z 位置与航向单环 |
| `pz -1` | Z 位置外环、Z 速度内环；外环期望速度限制为 ±0.08 m/s |
| `vz` | 只调试 Z 速度内环，期望速度沿用 -0.15 m/s |

`pidx/pidy/piddep/pidyaw/pidpz/pidvz` 设置基础参数。开启模糊模式时实际参数是基础参数乘以规则倍率；关闭时直接使用基础参数。

位置、航向和速度分别使用独立的误差分档。Z 单环的积分累加限幅为 6，积分分离阈值为 0.1 m；经典、模糊两种模式保持一致。双环保留原有各环的积分限幅，不套用 Z 单环的积分分离。

切换控制模式时清除历史；同一模式更新目标时保留积分。总开关不改写自主对接控制。`gait` 是步态控制，`a` 直接指定关节角，`grasp` 使用 ADRC，这些指令没有被改成 PID。

窗口与 `logs/robot_control_时间戳.log` 中的 `[MANUAL PID fuzzy]` 或 `[MANUAL PID classic]` 会记录通道、误差、实际增益、输出及积分状态，随实际控制更新打印。XYZ 原有的 30 Hz 快照继续保留。

新增航向和速度环的分档是初始配置，尚需 Gazebo 闭环实测调参。可以先分别测试 `dep -1`、`yaw 30`，再测试组合命令。

验证：

```bash
source devel/setup.bash
python3 src/asrobot/test/test_manual_fuzzy_pid.py
```

该测试使用临时 ROS master，仅启动 motion 并发送合成反馈，不连接或启动 Gazebo。

## 手动航向分配修正（2026-10-26）

`yaw` 和 `depyaw` 使用独立的手动偏航姿态：四个 H 关节命令为 `40,-40,40,-40` 度。
按当前 new_gazebo_model 的几何与校准，1/3 号正推力产生正偏航力矩，2/4 号产生负偏航力矩。
这样相同转速时近似平衡，差动转速能产生两个方向的力矩。
原来全部使用 `40` 度时，四个正推力力矩同向，无法靠差动转速反向制动。

窗口及日志新增 `[MANUAL YAW ALLOCATION]`，记录水平关节命令、航向/深度请求和分配推力。
模糊、经典航向 PID 的微分均按 360 度周期计算，并抑制首次计算的微分突跳。
此修正仅接入手动 `yaw/depyaw`；XYZ 与自动控制保持原分配路径。
模型几何和合成反馈测试通过后，仍须分别在 Gazebo 实测 `yaw 30` 与 `yaw -30` 的闭环收敛。
